# poke-team-builder

## Introduction
A React web app for building a competitive Pokémon team and analyzing its weaknesses. Add and delete Pokémon to build a team of 6 and compare type advantages.

## How to run on VS Code
1. In terminal run `npm install`
2. Then in terminal run `npm run dev`
3. A link will be shown in terminal, click it and local browser tab will open
4. Input Pokémon name in `Add Pokémon` text and press `Add Pokémon` button
5. To delete a Pokémon input Pokémon name in `Delete Pokémon` and press `Delete Pokémon` button
6. In terminal input `Ctrl+C` to quit
